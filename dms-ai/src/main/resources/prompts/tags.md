Choose two to six tags:
- the kind of document, for example invoice, contract, payslip, certificate or letter;

Prefer the existing tags and write them exactly as listed. Add a new tag only if no existing tag

new tags in the language of the existing tags, or in the language of the document if there are
none yet.
